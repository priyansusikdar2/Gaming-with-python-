# Alien Shooter Game

This is a simple 2D "Alien Shooter" game created using Pygame. The objective is to control a spaceship, shoot aliens, and avoid colliding with them.

## Features
- **Player Ship**: Controlled with the arrow keys to move left and right.
- **Bullets**: Shoot bullets by pressing the spacebar.
- **Aliens**: Aliens spawn randomly at the top and move downward. Shooting them increases your score.
- **Game Over**: The game ends when an alien collides with the player's ship.
- **Score**: The score increases each time an alien is destroyed.
